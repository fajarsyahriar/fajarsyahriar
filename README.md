## 🏛️ Prinsip Kerja & Rekayasa Sistem

1. **Substance over Hype**: Setiap baris kode, script, dan aset visual harus memiliki fungsi langsung terhadap kecepatan, kejelasan pesan, atau konversi bisnis.
2. **Speed is a Core Feature**: Waktu muat bukan sekadar angka benchmark, melainkan penentu retensi audiens, kepuasan pengunjung, dan peringkat mesin pencari.
3. **Structured & Agentic Crawlable**: Dokumen web ditata dengan semantik HTML5 bersih, Schema.org terstruktur, serta `llms.txt` agar mudah dipahami oleh peramban pengguna, bot perayap mesin pencari, maupun agen kecerdasan buatan (LLM).
4. **Security by Default**: Memadukan enkripsi edge SSL/TLS Full (Strict), proteksi form honeypot anti-spam, dan isolasi port server origin tanpa celah terbuka.
